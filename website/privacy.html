Política de privacidad

Última actualización: 27 de septiembre de 2026.

Ámbito de esta política

Esta política se aplica al sitio web corporativo de Vitalia. Las aplicaciones y servicios desarrollados por Vitalia pueden disponer de condiciones y políticas específicas según su finalidad y los datos que traten.

Datos tratados por este sitio

Este sitio es informativo. No incluye formularios, cuentas de usuario, analítica ni publicidad, y no solicita directamente datos personales a sus visitantes.

Servicios de terceros

El sitio se publica mediante GitHub Pages. Al acceder, GitHub puede tratar datos técnicos necesarios para prestar y proteger el servicio, como la dirección IP y los registros de acceso, de acuerdo con sus propias condiciones y políticas.

Enlaces externos

Los enlaces a servicios externos, incluido GitHub, llevan a sitios gestionados por terceros. Sus políticas de privacidad se aplican una vez que el visitante accede a ellos.

Contacto

Para realizar una consulta relacionada con este sitio o con la privacidad, contacta con Vitalia mediante su perfil de GitHub.

Esta política describe únicamente el sitio corporativo actual. Deberá ampliarse antes de publicar servicios que recojan datos mediante formularios, WhatsApp, asistentes u otras integraciones.
